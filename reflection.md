# Part 2: Reflection

## 1. Three new things I learned

I learned how to use semantic HTML sections and anchor links to connect navigation to page sections. I learned how CSS media queries can reorganize a layout for mobile, including turning an overlapping desktop design into a stacked one. I also learned that JavaScript can update a CSS custom property to change a page’s background color when a button is clicked.

## 2. Where I tweaked or corrected Copilot’s suggestions

I replaced generic sample text with details about my own background and current studies. I corrected the portrait size and layout so it displayed properly, and changed the design to better match my reference image. I also replaced generic symbols with relevant icons and made the navigation links bolder.

## 3. Copilot as a code generator vs. a learning partner

Generating code can help me get a first version quickly, but I still need to understand and test what it produces. As a learning partner, Copilot can explain how the code works, suggest alternatives, and help me investigate bugs. I learn more when I ask questions, evaluate the answers, and make the final decisions myself.

## 4. Three risks of relying too much on AI

I might submit code I cannot explain, making it harder to debug or build on later. AI can produce incorrect or inaccessible code, and I may miss those problems if I don’t test it. If I let AI do too much of the work, I get less practice and may become less confident solving problems independently.
